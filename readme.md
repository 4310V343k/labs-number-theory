# лабораторные по теории чисел

вариант №8

## структура репозитория

- [run_results.md](./run_results.md) результаты запуска программ

- `rgr/` расчётно-графическая работа перед 1 лабораторной
- - запуск с помощью `mise run rgr:1` (вместо `1` подставить номер задания или `*` для запуска всех заданий последовательно)
